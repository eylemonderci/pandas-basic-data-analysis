
#  Orta Düzey Programlama Projesi: Pandas ile Temel Veri Analizi

Bu proje, **Yönetim Bilişim Sistemleri** bölümünde verilen **Orta Düzey Programlama** dersi kapsamında geliştirilmiş olup, Python programlama dili ile yazılmıştır. Çalışmada `pandas` ve `numpy` kütüphaneleri kullanılarak rastgele üretilen öğrenci verileri üzerinde temel veri analizi işlemleri gerçekleştirilmiştir. Amaç, fonksiyonların çalışma yapısını öğrenmek ve veri işleme yetkinliğini geliştirmektir.

---

# Proje İçeriği

Projede yer alan temel işlemler şunlardır:

- **Veri Oluşturma**: Öğrenci verileri rastgele üretilmiştir (Yaş, Boy, Kilo, Bölüm, Vize, Final, Cinsiyet).
-  **Veri Analizi**:
  - DataFrame yapısı tanıtılmış ve veriler Pandas ile işlenmiştir.
  - Öğrenci bilgileri filtrelenerek belirli koşullara göre seçilmiştir.
  - Cinsiyete göre yaş ortalamaları ve bölümlere göre boy ortalamaları hesaplanmıştır.
  - Vize ve final notları ağırlıklı ortalama formülüyle birleştirilmiştir.
- **Fonksiyon Kullanımı**: Veri analizi içinde parametreli fonksiyonlar, işlem yapıları ve değer döndürme yapıları gösterilmiştir.
- **Gruplama ve İstatistiksel İşlemler**: `groupby()` ile gruplama, `mean()` ile ortalama hesaplamaları yapılmıştır.

##  Nasıl Çalıştırılır?

1. Bu repoyu bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/kullaniciadi/ornekgithubrepo.git
   ```
2. Gerekli kütüphanelerin kurulu olduğundan emin olun:
   ```bash
   pip install pandas numpy
   ```
3. Jupyter Notebook ortamında `.ipynb` dosyasını açın:
   ```bash
   jupyter notebook
   ```
4. Notebook dosyasındaki hücreleri sırayla çalıştırın.
